# CAMERA Integration — Passthrough Camera plugin + 4 camera games

## What was built

**Plugin** (`addons/ar_camera/`):
- `android/` — Gradle library module: Camera2 single-shot capture
  (`ARCameraCapture.java`), ZXing QR decode (`ARCameraQR.java`),
  plugin entry (`ARCameraPlugin.java`, singleton name `ARCamera`),
  `libs/zxing-core.jar` (3.5.3, pure Java, no Play Services).
- `ar_camera.gdip` + `ar_camera.aar` — the AAR is built in CI (fat AAR:
  plugin classes + ZXing merged via `tools/merge_zxing_aar.py`, tested).
- `README.md` — full build/privacy notes.
- GDScript: `scripts/shared/ar_camera.gd` (`class_name ARCamera`:
  `is_available()`, `request_permission()`, `capture()` → Image,
  `frame_size()`, `scan_qr()` → String) and
  `scripts/shared/camera_vision.gd` (`class_name CameraVision`:
  `analyze_colors`, `dominant_color_name`, `color_match_fraction`,
  `brightness`, `sobel_edges`, `edge_density`, `roundness`).
- QR codes: `assets/qr_codes/qr_1..5.png` + `qr_sheet.png`
  (generated by `tools/make_qr_codes.py`).
- Build tooling: `tools/build_camera_plugin.sh` (Gradle bundleRelease +
  ZXing merge + install to `android/plugins/`),
  `tools/merge_zxing_aar.py` (merge logic verified locally).

**Games** (all in `scripts/games/<slug>/` + `scenes/<slug>/`):
| slug | display name | category | description |
|---|---|---|---|
| `eye_spy` | Eye Spy AR | UTILITIES | Camera color/shape scavenger hunt, 10 rounds |
| `qr_hunt` | QR Treasure Hunt | GAMES | 5-clue QR chain with AR loot |
| `plant_doctor` | Plant Doctor | UTILITIES | Plant care plans + Holo Garden twin (user-selected species, no fake AI claims) |
| `sketch_3d` | Sketch to 3D | CREATE | Photo of a drawing → extruded 3D relief + gallery |

## Merge steps (for the release agent)

1. **Build the plugin AAR in CI** — add BEFORE the Godot export step in
   `.github/workflows/build.yml`:
   ```yaml
   - name: Build ARCamera plugin
     run: |
       wget -q https://services.gradle.org/distributions/gradle-8.7-bin.zip
       unzip -q gradle-8.7-bin.zip -d /tmp
       export PATH=/tmp/gradle-8.7/bin:$PATH
       export ANDROID_HOME=/usr/local/lib/android/sdk
       export ANDROID_SDK_ROOT=/usr/local/lib/android/sdk
       bash tools/build_camera_plugin.sh
   ```
   This compiles the library, merges ZXing, and installs
   `ar_camera.aar` + `ar_camera.gdip` into `android/plugins/`,
   which the Godot export picks up automatically.
   NOTE: `push_project.py`'s INCLUDE lists must gain
   `addons/ar_camera/` (minus `android/build/`), `tools/*.py`,
   `tools/*.sh`, `assets/qr_codes/`.

2. **Manifest permissions** — in `export_presets.cfg`, add to the preset's
   permissions list:
   - `android.permission.CAMERA`
   - `horizonos.permission.HEADSET_CAMERA`
   The godotopenxrvendors plugin already injects the HorizonOS camera
   permissions when CAMERA is enabled (per its changelog) — VERIFY on the
   first device test with
   `adb shell dumpsys package com.brioagent.nexusarcade | grep -i camera`.

3. **Hub entries** — the hub is being reorganized into category screens
   (GAMES / UTILITIES / CREATE / THEMES). Suggested placement:
   - GAMES tab: `["QR Treasure Hunt", "res://scenes/qr_hunt/qr_hunt.tscn"]`
   - UTILITIES tab: `["Eye Spy AR", "res://scenes/eye_spy/eye_spy.tscn"]`,
     `["Plant Doctor", "res://scenes/plant_doctor/plant_doctor.tscn"]`
   - CREATE tab: `["Sketch to 3D", "res://scenes/sketch_3d/sketch_3d.tscn"]`
   (Sky Traffic, the plane viewer, is also a UTILITY.)

4. **Version bump** — whichever release this ships in (suggested 0.6.0
   alongside the 10 mega games): bump `export_presets.cfg`,
   `project.godot`, and `version.json` together, and point the APK URL
   at the matching release asset name.

5. **First-device checklist** (Quest 3):
   - Grant camera permission when prompted; confirm `is_camera_available()`.
   - `captureFrame()` returns a JPEG; `scanQR()` decodes a printed
     `assets/qr_codes/qr_1.png`.
   - If the Camera2 camera-ID guess is wrong (black frames), the fix is in
     `ARCameraCapture.chooseCameraId()` — log available IDs via
     `adb logcat -s ARCamera` and pin the right one.

## Privacy note (for the store listing / email)

Camera frames are captured on demand, processed 100% on-device
(color/shape analysis, QR decode), and never uploaded anywhere.
The app requests the camera permission at first use; every camera game
has a full manual fallback mode when the camera is unavailable.
