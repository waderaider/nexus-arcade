How to Install

1. Enable Developer Mode

Open the Meta Horizon mobile app → Menu → Devices → select your Quest 3 → Developer Mode → ON.

2. Install the APK

  1. Download SideQuest from sidequestvr.com
  2. Connect your Quest 3 via USB
  3. In SideQuest, click the folder icon (Install APK)
  4. Select the downloaded file

Or via ADB: adb install NexusArcade-final.apk

3. Launch

On your Quest 3: Apps → Unknown Sources → NEXUS ARCADE
