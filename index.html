📱 NEW in v0.9.3: The Launcher Rework

wade's Quest 3 photos showed the v0.9.2 launcher rendered but the panel was absurdly close/huge with NO laser pointer visible. Rebuilt to the LAUNCHER LAW: one 2D panel, one scrollable list of all 75 experiences, laser + trigger. Panel is a fixed 1.60×1.00 m quad at 2.0 m, recentered on every menu open with a guard tick that pushes it back out if you walk into it. Belt-and-suspenders input: a new DirectUIInput fallback draws its own bright-yellow beams and injects clicks on raw trigger/pinch rising edges even if the primary pointer path dies; thicker primary lasers, deduped clicks. On-screen diagnostics ship-blocker: plain-words input state, ⚠ NO INPUT SOURCE LIVE self-test warning, boot timer, live readout — plus a Test connection button that POSTs a ping to the crash-log relay and shows SUCCESS/FAILED. Pause menu reordered: Resume → Controls → Restart → ◀ Prev / Next ▶ → EXIT TO LAUNCHER (red, full-width, bottom, unmissable). Relay URL now compiled in as a fallback — prime suspect for zero device reports ever arriving. Staged boot targets first frame <2 s. Not Quest-tested on real hardware — your headset pass is the validation.

⏬ NEW in v0.9.2: Flip Through Games

The pause menu now has ◀ Prev and Next ▶ buttons showing the next game's name — flip through all 75 experiences without going back to the launcher grid (wraps around at the ends). Works with controller laser, hand pinch, gaze dwell, and mouse. Fixed: the launcher aurora background shader never compiled under Godot 4 (Godot 3 syntax) — it actually renders now. New permanent system: gameplay telemetry — the app now logs tiny batched gameplay events (game start/end, duration, quit point, pause opens, next/prev usage, input method) to the crash-log relay so play data drives automatic improvements. Gameplay events only, never personal data. Not Quest-tested on real hardware — your headset pass is the validation.

🧬 NEW in v0.9.1: The Tidy Version (light cycle)

Verification pass: exit-to-launcher now attaches unconditionally on every game launch (a structural fix — no game can silently lose its exit path), and the gray-primitive CI audit is clean on all art-fix games. Art fixes: Holo Aquarium fish are now animated 3D fish, Holo Pets' Wisp is a real animated pug, Wizard Academy has real potion bottles plus grab/pour juice, the Mummy Wrap mummy ships pre-wrapped in bandages, and the Werewolf Howl werewolf is a real wolf model. New: Sky Traffic planes now rumble — engine roar follows each plane's real distance. No boring games found among the touched titles; 75 experiences remain. Not Quest-tested on real hardware — your headset pass is the validation.

🎆 NEW in v0.9.0: Everything Comes Alive

22 boring games cut — wade’s permanent quality bar: anything that wasn’t amazing got removed outright (CUT_LIST.md). 75 experiences remain, and every one now has working music (genre soundtracks finally play, with explore/tense/combat intensity layers), 3-second skippable title cards, a pause menu in every game (menu button or Esc — Resume / Restart / Quit to Hub, works with laser, pinch, and gaze), controller skins (1:1 render models with game-styled grips + per-game button legends), passthrough FX (dragon fire scorches your real walls, splashes ripple your floor, portals anchor to walls), and per-game color grading for your real room. Launcher 2.1: key-art cards, daily Spotlight row, 4 category skins, Depth FX toggle (virtual objects hide behind real furniture). New: Mano Mágica hand-tracking tour. XR upgrades: simultaneous hands+controllers, body tracking in Skeleton Dance, grab/throw physics. Targets Android SDK 34. Not Quest-tested on real hardware yet — your headset pass is the validation.

How to Install

1. Enable Developer Mode

Meta Horizon app → Menu → Devices → your Quest 3 → Developer Mode → ON.

2. Install the APK

  1. Download SideQuest from sidequestvr.com
  2. Connect Quest 3 via USB
  3. In SideQuest, click Install APK (folder icon)
  4. Select the downloaded file

Or via ADB: adb install NexusArcade-v0.9.3.apk

3. Launch

Quest 3: Apps → Unknown Sources → NEXUS ARCADE

4. Stay updated

The in-app Check for Updates button in the hub notifies you when a new version drops.
