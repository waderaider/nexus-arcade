How to Install

1. Enable Developer Mode

Meta Horizon app → Menu → Devices → your Quest 3 → Developer Mode → ON.

2. Install the APK

  1. Download SideQuest from sidequestvr.com
  2. Connect Quest 3 via USB
  3. In SideQuest, click Install APK (folder icon)
  4. Select the downloaded file

Or via ADB: adb install NexusArcade-v0.12.0.apk

3. Launch

Quest 3: Apps → Unknown Sources → NEXUS ARCADE

4. Stay updated

The in-app Check for Updates button in the hub notifies you when a new version drops.

🎮 MARIGOLD UE5 RTX Demo — Your Tasks

One-chapter ray-traced demo of the candle-lit Ofrenda, built for your RTX 5070 Ti and streamed to Quest 3 via Virtual Desktop.
Your PC is the build host — here's everything on your plate.

Step 1 — Install these now YOUR TURN

  • TODOUnreal Engine 5.7.x — Epic Games Launcher → Unreal Engine → Library → install latest 5.7.x (~50GB). Start this first; it's the long pole.
  • TODOMetaXR plugin v203.0 — developer.meta.com → Downloads → Unreal Engine 5 Integration.
  • TODONVIDIA DLSS 4.5 plugin (UE 5.7 build) — developer.nvidia.com/rtx/dlss. Super Resolution only; Frame Generation stays OFF (not VR-safe).
  • TODOVisual Studio 2022 (free Community) with the "Game development with C++" workload — required to package. Install while the engine downloads.
  • TODOVirtual Desktop Streamer on the PC — skip if already set up for the Godot PC build.

Needs: 120GB free on your fastest drive, a free Epic Games account, a free Meta developer account. Freeze rule: stay on UE 5.7.x — decline any 5.8 update (DLSS plugin is version-pinned).

Step 2 — Files are ready READY

  • READYProject files — v0.2.0: the .uproject + one-click "Build Demo Content" script + MarigoldBuilder/MarigoldFX plugins + Guanajuato environment.
  • READY35 models + 38 audio files — staged with licenses verified; they ship inside the project package.

Download from the ⬇ Downloads section below.

Step 3 — Build it (when the files arrive)

  • TODOOpen the .uproject — first open compiles shaders: 30–90 min unattended on the 5070 Ti. Walk away.
  • TODORun "Build Demo Content" (one click) — imports all assets, builds materials, constructs the Ofrenda-night scene, wires the 25 candle lights, sets Lumen / MegaLights / DLSS.
  • TODOPackage → Windows .exe — 20–60 min the first time; faster after that.

Step 4 — What comes back to us

  • Screenshots / logs if the build script throws errors — we fix the script, you re-run. No reinstall needed.

🔊 Openverse audio pipeline YOUR PC NEEDED

Openverse has no user accounts (it's search-only), and its API blocks my cloud machine — so this part runs from your PC. Two quick steps, both free:

  • Step 1 — get a free API key (2 min, one command in PowerShell/Terminal):
    curl -X POST https://api.openverse.org/v1/auth_tokens/register/ -H "Content-Type: application/json" -d '{"name":"brio-game-audio","description":"SFX and music for my indie VR games","email":"brio@agentsmail.net"}'
    Save the client_id and client_secret it returns (shown once).
  • Step 2 — pull audio: download the tool (ov_audio.py, plain Python, no installs), then:
    python ov_audio.py pull "mariachi" --kind music --out ./marigold_audio
    python ov_audio.py pull "church bell" --kind sfx --out ./marigold_audio

Send me the client_id/secret and I'll wire it into the pipeline for higher limits. The tool works for every game — NEXUS and MARIGOLD.
