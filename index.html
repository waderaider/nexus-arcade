How to Install

1. Enable Developer Mode

Meta Horizon app → Menu → Devices → your Quest 3 → Developer Mode → ON.

2. Install the APK

  1. Download SideQuest from sidequestvr.com
  2. Connect Quest 3 via USB
  3. In SideQuest, click Install APK (folder icon)
  4. Select the downloaded file

Or via ADB: adb install NexusArcade-final.apk

3. Launch

Quest 3: Apps → Unknown Sources → NEXUS ARCADE
